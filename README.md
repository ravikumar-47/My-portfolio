# Portfolio

A showcase of websites built for small businesses — designed and built with AI tools, mobile-first, and made for fast loading.

## Live site
https://ravikumar-47.github.io/My-portfolio/

## What's inside
- `index.html` — page structure
- `styles.css` — all styling
- `config.js` — name, tagline, email, social links (edit this to update your details)
- `portfolio-data.js` — project list shown on the site (edit this to add/remove projects)
- `main.js` — renders the config and project data onto the page

## Editing
No build step, no install needed — just edit the text inside `config.js` and `portfolio-data.js`, save, and refresh the page.
